# Third-party sources

- `solar_filaments/vendor/flash_intern_image.py` is adapted from OpenGVLab/DCNv4, commit `4b848f7dd7da74ff03f7d278f902c6fd05b391b5`, `classification/models/flash_intern_image.py`. Its copyright header and MIT license are preserved in `LICENSE.OpenGVLab`. Adaptations change imports and activation checkpoint API, not the backbone computation or tensor names.
- The optional CUDA extension is fetched from the same pinned repository by `scripts/build_dcnv4.py`. Its original source headers include OpenGVLab MIT notices and Deformable DETR / SenseTime Apache 2.0 notices. Those headers remain in the fetched source. Local compatibility changes narrow CUDA-side headers and omit imports of the unrelated FlashDeformAttn Python module. The project's wrapper also selects valid backward launch geometries for the L model's large group counts. CUDA kernel arithmetic is unchanged.
- The curve operator is a new PyTorch implementation inspired by Qi et al., ICCV 2023, *Dynamic Snake Convolution Based on Topological Geometric Constraints for Tubular Structure Segmentation*. It does not copy the DSCNet implementation or include its topology loss.
- The query decoder uses established set prediction, mask-guided cross-attention, and bipartite assignment ideas. It is implemented here without importing a detector or segmentation framework.
- The per-instance soft skeletonization / clDice objective is independently implemented from the mathematical construction in Shit et al., CVPR 2021, https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html . No code from the authors' repository is vendored. It is a shape regularizer, not an implementation of the official discrete PQ metric.
- The Haar transform is the standard orthogonal 2x2 transform. Related segmentation work: Xu et al., *Haar wavelet downsampling*, Pattern Recognition 2023, https://doi.org/10.1016/j.patcog.2023.109819 . The transform is invertible; the following learned projection is not guaranteed invertible.
- Related objective design references: Wang et al., *MaX-DeepLab*, CVPR 2021, https://openaccess.thecvf.com/content/CVPR2021/html/Wang_MaX-DeepLab_End-to-End_Panoptic_Segmentation_With_Mask_Transformers_CVPR_2021_paper.html ; Chen et al., *Mind Marginal Non-Crack Regions*, CVPR 2024, https://openaccess.thecvf.com/content/CVPR2024/html/Chen_Mind_Marginal_Non-Crack_Regions_Clustering-Inspired_Representation_Learning_for_Crack_Segmentation_CVPR_2024_paper.html . The native-area IoU calibration, competition loss and modest boundary weighting in this project are adaptations, not reproductions of either complete method.
- Pretrained weights are the author's FlashInternImage-L ImageNet-22K-to-1K model. Author repository: https://github.com/OpenGVLab/DCNv4. Original HF filename: `flash_intern_image_l_22kto1k_384.pth`. Original SHA256: `c694efa31c67cc246d836513080da98861a46a8ba3cee5d0dc6a8074f1a4384d`. Runtime tensor-only backbone files retain provenance manifests; weight rights remain with their original providers.
- Competition images and annotations are not included in the source archive. Their dataset license and competition rules remain applicable.
